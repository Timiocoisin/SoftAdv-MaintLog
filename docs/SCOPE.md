# Release scope

## Claims supported by this repository

- Soft-advisory loop definition: camera \(\hat g\) vs handwritten \(g\), inspectable MetalField gate, site-tunable OK/ALERT, no grinder interlock.
- Audit-OrdNet / MetalField implementation used as the laboratory readout carrier.
- Protocol and operating-point tables under `release_tables/` for hard stage-gap / proxy / alert boards.

## Explicit non-claims

- Multi-wall or in-plant deployment readiness.
- Architecture or progress-head SOTA over generic ordinal/progress baselines.
- Complete from-scratch reconstruction of every historical seed run without the laboratory frames and checkpoints.
- Continuity with the retired PASS-Ord CNN–RF nested protocol (different supervisory framing).
